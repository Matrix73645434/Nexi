# CLAUDE.md — Nexlock

Nexlock — мобильный мессенджер (интернет-чаты с E2EE) + Radio Chat через физические устройства Nexlock (ESP32 WROOM + LoRa E22-400T30D).

## Текущее состояние

- **Фаза:** архитектура утверждена (решения — `docs/ARCHITECTURE.md`, раздел 13). Следующий шаг — этап 1. Код Nexlock ещё не начат.
- Nexlock будет вестись в **отдельном репозитории**; эта ветка `Nexi` — временное место для документов.
- Стек: React Native + Expo + TypeScript; сервер Fastify + PostgreSQL + Redis.
- Архитектура и план: `docs/ARCHITECTURE.md`.
- Брендинг: `assets/brand/app-icon-1024.png` (иконка приложения), `assets/brand/avatar-placeholder-1024.png` (аватар по умолчанию, когда у пользователя нет фото); исходники — `*-source.png` / `avatar-placeholder.png`.
- В корне лежит не связанный с Nexlock PWA-прототип «Nexi» (`index.html`, `sw.js`, `manifest.json`, `icon.svg`, `IMG_*.jpg`). Не удалять без решения владельца.

## Идентификаторы (решение владельца)

- **UID** — ID пользователя `NX-XXXX-XXXX`, выдаётся сервером случайно при регистрации, **неизменяем**, единственный ключ поиска пользователей.
- **DID** — ID устройства, выводится из его Ed25519-ключа.
- **MID** — ID сообщения в Radio Chat (`src` + `counter` радиокадра).

## Правила разработки

1. Работать поэтапно (см. `docs/ARCHITECTURE.md`, раздел 12). Не реализовывать всё сразу.
2. Не добавлять функции вне концепции без обсуждения.
3. Любая заглушка явно помечается (в коде — `// STUB:` комментарий, в UI — видимая плашка). Radio Chat без железа — только `DemoRadioTransport` с плашкой «ДЕМО»; никогда не отправлять «радио»-сообщения через интернет.
4. Не писать собственную криптографию: libsignal (интернет-чаты), libsodium (радио), mbedTLS/libsodium (прошивка).
5. Сервер не хранит OTP и refresh-токены в открытом виде; содержимое сообщений видит только как ciphertext.
6. Ghost Mode обеспечивается и сервером (отбрасывает `read`-квитанции пользователя в ghost-режиме), а не только UI.
7. Модульная структура: каждый модуль — своя папка, взаимодействие через публичный `index.ts`.
8. После каждого этапа — проверка (тесты/typecheck/ручной прогон) и обновление этого файла.
9. Не удалять работающие функции при добавлении новых.
10. Сквозное шифрование — во всех чатах по умолчанию (не как обычные чаты Telegram).
11. PIN против перевыпуска SIM — хэш Argon2id, ограничение попыток.
12. Радиопараметры (частота, мощность) — конфигурируемые, по умолчанию в безопасных для региона пределах.

## Визуальный стиль

Космос + технологичность + сетчатая червоточина. Цвета: чёрный, тёмно-синий, графит; акценты голубой/циан (иконка добавляет переход циан → фиолетовый).
